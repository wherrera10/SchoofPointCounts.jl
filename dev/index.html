SchoofPointCounts

SchoofPointCounts implements Schoof's algorithm for counting points on elliptic curves over finite fields, using Nemo.jl.

schoof(A, B, q)::Integer # All arguments are handled as integers
schoof(A::Nemo.FinFieldElem, B::Nemo.FinFieldElem)::Integer # Both arguments are Nemo.FinFieldElem type values

Both methods return the number of points on the curve y^2 = x^3 + A*x + B over a finite field. The integer method takes a prime-power field order integer q = p^k and integer coefficients A and B, which are interpreted in the prime subfield. The two-argument method takes coefficients from the same existing Nemo finite field. The field characteristic must be greater than 3, and the curve must be nonsingular, or an argument error will be thrown.

For example, to count the points on elliptic curve

y^2 = x^3 + x + 1

with prime p = 5 and k = 1, so that q is 5:

julia> using SchoofPointCounts

julia> schoof(1, 1, 5)
9

Note that the return value is the number of points on the projective elliptic curve; its affine points are supplemented by the single point at infinity, so the point at infinity is included in the returned count.

Ecosystem notes

Nemo.jl does include elliptic-curve research code, as does the separate EllipticCurves.jl project. Nemo's research code includes Frobenius computations used in Schoof–Atkin–Elkies point counting, but that is not the same as the general-purpose Schoof implementation of schoof implemented here. OSCAR.jl uses calls to the PARI library to provide a call to a Schoof–Atkin–Elkies algorithm for its order() function. Hecke.jl, part of the OSCAR project, uses a linear algebra-based general algorithm for its order() function.

Installation

You may be able to install the package from the Julia REPL in the usual way with ]add SchoofPointCounts, or to install from the current GitHub archive:

using Pkg
Pkg.add(url = "https://github.com/wherrera10/SchoofPointCounts.jl")

Requires Julia 1.10 or later, plus Primes.jl and Nemo.jl, which should be added automatically.

SchoofPointCounts.comparepoints — Method
comparepoints(P, Q, ψ) -> :equal | :opposite | :different

Compare points represented by (a, b) as (a(X), Y*b(X)), with Y^2=f. nothing represents infinity. For odd-index division polynomials on a nonsingular curve in characteristic different from the index, gcd(f, ψ)=1: an odd-order torsion point cannot be a nontrivial point of order two. Thus f is a unit modulo ψ and every factor of ψ. If the comparison differs on only part of the quotient, throw NotInvertible with a gcd.
